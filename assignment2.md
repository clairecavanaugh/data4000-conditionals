# DATA 4000 – Conditional Logic for Business Decisions

Python programs using `if`, `elif`, and `else` to apply business rules. One program per problem.

| File | Problem |
|------|---------|
| `problem1_discount.py` | Customer Discount Eligibility |
| `problem2_bonus.py` | Employee Performance Bonus |
| `problem3_loan_risk.py` | Loan Risk Classification |

## How to run

```
python3 problem1_discount.py
python3 problem2_bonus.py
python3 problem3_loan_risk.py
```

Each program prompts for its inputs and prints the result. No external libraries are required.
